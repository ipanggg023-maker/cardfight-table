# Vanguard Table

Private fan-made Cardfight!! Vanguard simulator (online, 2 players, each on their own device; no one-screen play since 2026-11-19). Not for sale.
The user writes Thai; they asked for replies in English to save tokens. Keep in-game text English.
Card data: the user asked (2026-11-13) for a one-click import of the whole card list. It runs in the editor (Card library → "Import every set") and stores the cards in the user's own database (browser IndexedDB, then their private Supabase). Never commit Bushiroad card text, lists or art to this repo (it is public). On 2026-11-13 the user asked to check the reader against every card on en.cf-vanguard.com: `tools/card-census/fetch-official.mjs` reads the site's own list API politely into the gitignored `tools/card-census/official/` (local checking only; don't put it in the app or the repo). The user adds pictures themselves. Since 2026-11-13 the user enters every card by hand in the editor (paste the card page into "Fill from card text") and does not use the Card library; leave the library/import alone unless asked.

## Sign-in & accounts (Supabase)
`js/auth.js`: two kinds of user, both cached in localStorage `vt-user` so pages read it at once. Guest `{name, color, guest: true}` (this computer only, no coins/Store). Account `{id, name, color, role: "player"|"admin", coins, guest: false}` from Supabase. Pages call `Auth.require()` in <head> (redirects to login; for accounts it also runs `Cloud.check()` after load: re-reads the profile, kicks to login if signed out/banned, fires a `vt-user` event). `Auth.isAdmin()`. `mountUserChip()` shows role + coins.
- `Cloud` (same file): lazy-loads supabase-js 2.45.4 from jsdelivr (so guests and the test table work offline); `signUp`, `signIn`, `signOut`, `refresh`, `saveProfile`, `rpc(fn, args)`. Project URL + publishable key in `SUPA` (public by design; never put the secret/service_role key in the repo).
- Database: SQL files in `supabase/`, run in order in the dashboard SQL Editor (or via the Supabase MCP in `.mcp.json`). `001_accounts.sql`: `profiles` (role, coins, banned; players can only update their own name/color), `admin_log`, `is_admin()`, trigger that makes a profile on sign-up (the first account ever becomes admin), admin RPCs `admin_set_role`, `admin_add_coins`, `admin_set_banned`. Rule: anything about roles, coins, packs or rewards is decided in SQL (security definer functions + RLS), never trusted from the browser.
- `002_cards_decks.sql`: `cards` (id, data jsonb = the editor card, deleted flag, server-set updated_at; everyone signed in reads, admins write), `decks` (owner + id, data; owner only), private Storage bucket `card-images` (signed in read, admins upload). `js/db.js` keeps IndexedDB as the local copy and syncs it for accounts: first DB call per page pulls (cards since `vt-cards-at`, the account's full deck list), writes go local first then through the outbox `vt-outbox-<uid>` (batches of 200; data: pictures uploaded to Storage and stored as `sb:<path>`, pages get signed URLs cached in `vt-img-urls`). First sign-in on a browser uploads its local decks (and local cards for admins). Players: `DB.put("cards")` throws, editor hides Cards / Card library / Online cards / Formats tabs (`DB.canEditCards()`)
- `003_store.sql`: `app_settings` (one row: start_coins, require_collection, win_coins, loss_coins, daily_match_cap; admins edit), `collection` (owner, card_id, count; read own, no direct writes), `boxes` (name, description, cover card id, price, cards_per_pack, rates jsonb weight per rarity, guarantee = minimum rarity of the last card, active, sort) + `box_cards` (box_id, card_id, rarity C/R/RR/RRR/SP/SEC), `pack_log`. RPC `open_pack(box, packs 1–10)` locks the profile, takes coins, rolls each slot (rarity by weight among rarities the box has, last slot ≥ guarantee, then a random card of that rarity), adds to collection, returns {packs, coins}. `admin_give_card`. New accounts get start_coins.
- `store.html` + `js/store.js`: Store (boxes, rates shown, Open 1 / Open 10, card flip reveal `.pk`), My collection (filter by box, show missing), admin tabs Manage boxes (box form, rarity weights, search the library and add cards with a rarity, "Add all results") and Settings (+ give yourself coins). Guests see a note.
- `007_store_decks.sql`: Store products are booster packs or decks. `boxes.kind` ('booster' | 'deck'), `boxes.deck` jsonb (deck layout {name, format, energy, ride, main, g, starter}), `box_cards.qty` (copies). RPC `buy_deck(box)` takes the price once, adds every card × qty to the collection, logs to pack_log, returns {cards, deck, coins}; `open_pack` refuses deck products. store.js: the Store shows "Booster packs" and "Decks" sections (`boosterHTML` / `deckHTML`, deck list folded); buying copies the deck into the buyer's decks. Manage boxes: Product toggle 📦 Booster / 🃏 Deck; a deck product is made by picking one of your decks (`renderDeckEdit`). Without 007 the page still works (`st.noDecks`, deck toggle disabled)
- `008_bosses.sql`: boss events. `bosses` (name, blurb, deck jsonb layout copied from the admin's deck, level easy/normal, adv jsonb {maxDamage, extraDraw, vcPower}, reward, starts_at, ends_at, active; signed in read, admins write), `boss_wins` (boss_id + owner primary key, turns, coins, at; own or admin read, no direct writes). RPC `claim_boss_reward(boss, turns)` → {status paid / already / closed / short / guest, coins, balance}: open and within its dates, not banned, turns ≥ 3, once per player per event (the primary key), coins added in the same transaction.
- Deck builder for players with an account: `Cloud.owned()` → `owned` map; `cards` = owned cards only (`allCards` keeps the library for lookups), + refuses more copies than owned, `ownErrors()` lists over-limit cards. No limit for admins, guests, offline, or when the admin turns require_collection off. Lobby hides the Card editor tile for players and has a Store tile.
- `004_matches.sql`: `matches` (id uuid from the host, p1 < p2 account ids, report1/report2 {winner, turns}, status waiting/paid/mismatch/short, coins1/2). RPC `report_match(match, opponent, winner, turns)`: the first report per player counts; when both are in and agree and turns ≥ 3, each player gets win_coins / loss_coins (draw = loss_coins) unless they already had daily_match_cap paid matches today (UTC). Returns {status, coins, balance, capped}. Online: hello carries the guest's `uid`, `Net.startHosted(names, decks, mats, uids)` makes a new `Net.match` {id, uids} every game (rematch too) and sends it in "start". ui.js `reportMatch()` runs once per match id when the game ends (retries while "waiting") and fills `#winCoins`. Test-table games and guest opponents never pay.
- `005_admin.sql`: `admin_users()` (profiles + email + last sign-in from auth.users + card/match/pack counts), `admin_rename`. `admin.html` + `js/admin.js` (admins only; others are sent to the lobby): Players table (search, filter admins/players/banned) with a side panel: rename, give/take coins, make admin/player, ban/unban, give cards by search, the player's collection with −1; Matches (last 200, both reports), Packs (last 200 with cards), Admin log (readable lines). Lobby shows an Admin tile for admins; Store has an Admin link. New admin tools go on this page.
- Plan: 1 accounts → 2 shared card library + cloud decks → 3 collection → 4 Store/gacha → 5 match coins → 6 admin page: all done. Gacha uses play-earned coins only, never real money.

## Loading screen & 60 fps
- `js/loader.js` (in every page <head>, right after auth.js): loading screen from first paint until window load + fonts + `Loader.wait(promise)`; min 1 s, max 5 s. App links fade it in, then navigate (`Loader.go(url)`); `Loader.canLeave` lets a page veto (editor: unsaved changes). `Loader.show(msg)` returns hide() for in-page work; `Loader.progress(0..1)`. The game uses it at start/join/rematch while `Pics` loads (`loadingTable()`).
- 60 fps rules: never rebuild big lists/tables on small changes. Patch in place (`setHTML` skips unchanged HTML; game: `renderSide`/`placeCard`/`renderHand`; editor deck builder and Quick deck are built once then patched, + / − only updates counts). Draw long picture lists in chunks (`fillChunked`, 48 per task). Debounce typing. Only animate transform/opacity; no layout properties (margin, width) or filters in transitions. Never wait on requestAnimationFrame alone (paused in background tabs): pair it with a timer.

Card: `{id, name, grade, type: unit|trigger|order, power, shield, crit, trigger: null|crit|front|draw|heal|over|stand, trigPower?, drive?, boost?, intercept?, sentinel, persona, nation, race, image, text, abilities[]}`. Missing drive/boost/intercept fall back to grade (Twin Drive on G3+, Boost on G0–1, Intercept on G2); missing trigPower = 10000 (over 100M)
Ability: `{kind: AUTO|ACT|CONT|ORDER|BLITZ, zone, when, once: ""|turn|game, mandatory?, conds[], costs[], effects[]}`; each row is `{type, ...params}`. `mandatory` AUTOs resolve without asking (no "you may"). `when: "overDrive"` = an over trigger's own text, only on drive checks
Deck: `{id, name, format, energy, ride:[4 card ids G0..G3] (Standard), starter: card id (formats without a ride deck: a G0 that is one of the 50), main:[50 card ids]}`. Card also has `clan` (older cards), `icon` ("D"|"V"|"-"|"" = auto), `regalis`; G units: `type: "g"`, grade 4, `gKind: "stride"|"guardian"`, `ultimate`, drive 3 by default. Deck also `g:[ids]`, `gUnlock`

## Engine notes
- `S.active` = turn player, `S.controller` = who must act now (defender while guarding, chooser during `S.pending`)
- Choices: `choose(pi, prompt, options, min, max)` returns a Promise; UI calls `Game.answer(ids)`. Auto-resolves when there's no real choice
- Slots `{card, rest, pow, crit, powB, critB}`; pow/crit reset at end of turn, powB/critB at end of battle. CONT bonuses computed live in `power()`/`crit()`
- Phases: mulligan → ride → main → battle → (endTurn) ride…. `S.first` = who went first (random unless chosen); both players draw every turn; no attacks on turn 1; mulligan = bottom, draw, shuffle
- Check timing (CR 11.6): `fire()`/`collect()` put AUTO abilities in `S.queue`; `checkTiming()` runs rule actions, then the turn player resolves their waiting abilities in the order they pick (prompt when 2+), then the other player; abilities triggered while one resolves (`depth`>0) wait. Simultaneous events (attack+boost+attacked, placedRC+allyPlacedRC, riddenUpon+placedVC, turnStart+oppTurnStart) are collected together first
- Stride / G zone (CR 6.5, 9.8, 14.12–14.16): decks have `g:[≤16 G unit ids]` (Premium/Extreme; Standard only with `deck.gUnlock`). Player `gDeck` (face down, hidden from the opponent online) and `gUp` (face up). Phase `stride` sits between ride and main when `canStride()` (both vanguards G3+ or yours was G3+ at turn start, hand grades ≥3): `Game.stride()` (pick G unit, discard total grade 3+, old vanguard → `slots.vc.heart`, power adds the heart's, names include it) or `skipStride()`. End phase `returnGUnits()`: G units → `gUp`, heart back to vanguard. `leaveCircle()` sends G units to the G zone instead of drop/bind. `gGuard()` in the guard step (both vanguards G3+, ≤3 face-up G guardians, default cost: discard a grade 1+ card [unverified]); G guardians go to `gUp` at end of battle. Printed stride cost: card `strideCost` {name, grade} (discard one such card) / {sameNameVC} / {sum: N}; blank = grades total 3+ (`strideCostOf()`); `discardAs` N ("may be discarded as a grade N") and `strideGrade` count toward it; read from text by TextParse.stats and copied on import. Ultimate Stride needs 3 face-up G cards and removes the whole G zone when it returns. Conditions `genBreak` / `limitBreak`, event `onStride`
- Circles are per player: `frontOf(pi)`, `rcOf(pi)`, `unitsOf(pi)` = the 6 standard circles + accel circles (`x1`, `x2`… from `p.accel`). Use these, not the FRONT/RC/UNITS constants, for anything about a player's field
- Imaginary gifts (CR 16): card field `gift` (force/accel/protect); riding it calls `giveGift()` before the ride's AUTOs; one gift type per player from rides (`p.giftType`), I/II chosen once per type (`p.giftVariant`). Force I/II and Protect II are markers in `p.marks[circle]`; Accel adds `p.accel` circles (drawn outside the mat edges in ui.js); Protect I is a pseudo-card `{protect:true}` in hand that only lives in hand/GC (erased by `ruleActions()`). Bonuses in `giftPower()` (your turn only) and `crit()`. Not in Extreme. Effect block `gift`
- Legion (CR 6.4, 14.11): effect `seekMate` (name contains) puts the mate in `slots.vc.mate` (power added, names included, drive/crit from the leader; riding puts both in the soul; stride keeps it as `heartMate`); cost `dropToTop` (N drop cards to the deck top, optional max triggers for D-Seek Mate); condition `legion`; a unit legions once (`p.legionUsed`)
- D era: card flags `setOrder` (→ `p.orderZone`; abilities with zone `OZ` work there: CONT in `cont()`, AUTO via `collectAll()`, ACT via `orderZoneActs()`/`activateOrderZone()`), `arms` + `armsName` (attaches to `slots.vc.arms` when the vanguard's name matches; its abilities act as the vanguard's via `sourcesAt()`; dropped on a different-name ride), `alchemagic` (adds a normal order from the drop: conds/costs/effects appended), `regalis` (`p.regalisUsed`, once per game; a 2nd goes to drop), `dress` + `overDress` (name filter) / `xoverDress` ("A | B"): `Game.overDress(uid,key)` / `xoverDress(uid)`, old units in `slot.under` (originalDress, drop when the unit leaves), event `dressed`; ability `once: "divine"|"unique"` (one per game across all cards); `p.world` with effect `setWorld` and condition `world`; `ace` (≤1 per deck)
- Lock / Delete / Time Leap (CR 7.30–7.33): `slot.locked` (face down, no info/abilities, not a unit for effects, can't attack/boost/intercept/be attacked, circle can't be called to), `slot.deleted` (vanguard: printed power and text gone), `slot.timeLeap` (bound card's uid). The turn player's locked/deleted cards return and Time Leap swaps back in `endPhaseReturns()`. Effects `lock`, `unlock`, `delete`, `timeLeap`; event `unlocked`
- Ability Language v2 (steps 1–3): filters `match(card, f, {pi, ctx})` also take clan (nation/clan/race contains), trig, nameExact, sentinel, sameNameVC, gradeVC (lt/le/eq/ge/gt/plus1 vs your vanguard), other (not this card), ctype g; editor `filterHTML()`. Counts `countOf(pi, what, filter, ctx)` (SCHEMA.paramOptions.count: your/opponent zones, units, face-up damage, energy, battleNo = `S.battleNo`, lastCount/lastMatch); condition `count` {what, op, n, filter}, condition `unit` {who: vc/self/oppVc/attacker/attacked, filter}, `wentFirst`/`wentSecond`; "for each" = `per` + `perFilter` on power/crit/draw/CC/SC/EC (also in CONT). **Move cards** (effect and cost `move`): `moveCards()` {from: self/hand/deck/deckTop/drop/soul/damage/bind/gzone/orderZone/myRC/myFrontRC/myBackRC/opp…, to: hand/RC/soul/drop/deckTop/deckBottom/bind/damageUp/damageDown/removed/orderZone, n, upTo, all, random, look, rest, chooser me/opp, reveal, filter}; cards go to their owner's zones. ## Adding a new ability block
1. Add it to `SCHEMA.effects` (or conds/costs/events) with `label`, `params`, `text()`
2. Handle the same `type` in `effect()` / `condOK()` / `canPay()`+`pay()` in engine.js, or `fire(...)` the new event at the right moment
3. The editor picks it up automatically. Test by building a card with it and playing a game

Decisions use `Game.snapshot(seat)` only for hidden zones (fair); public helpers (power, canAttack, boosterFor, attack/defense power, actList) read the open table. `run()` polls every 20 ms until the action ends or stops for a choice (on-screen pauses can take seconds), so the bot never waits on its own question. ui.js `botTick()` after each render: 600 ms think time (`Bot.THINK_MS`), plate shows "thinking…".
- Normal: mulligan extra grade 3s; ride deck first, discard the least useful card; strongest units to the front, boosters behind, replace only when +5000, keep 2 shields from 3 damage; ACT abilities when ready (max 3 a turn); rear-guards attack before the vanguard (vanguard first when the opponent has 5 damage); guard by its damage and who attacks (0–2: only a vanguard attack, only if one card covers; 3: vanguard attacks; 4–5: everything, just enough shield +5000 vs a vanguard; sentinel at 5 when nothing else covers); intercept first from 3 damage; trigger power to the next attacker, critical to the vanguard; stride once a turn, discarding the highest grades.
