      Card library

      Free card data from the Card Game Simulator community files on GitHub. No key needed. Pick a set, or load all sets once to search by name (about 18 MB).

      Filter

      The files have no trigger icons. When a trigger's text doesn't say its type, pick it from the picture before importing. Cards left on "?" are marked ⚠ in the Cards tab.

      Formats & restriction lists

      Each deck has a format (pick it in the deck builder), and the deck check follows that format's rules. Restriction lists change a few times a year: copy the current ones from the official Deck Construction Rules page (cf-vanguard.com → How to play → Fighter's Rules) into the lists below. They are saved in this browser.

      Backup

      Cards live inside this browser. Export regularly and keep the file in D:\Vanguard so nothing is lost if browser data is cleared. Share the file with a friend so they get the same cards.

      Link card pictures

      Put the pictures in a folder inside D:\Vanguard (for example images), then pick that folder here. Each file is matched to a card by its file name: the card name (Rewrite the Star, Vyrgilla.png) or the card number (DZ-BT01_001EN.png). Matched cards get the picture; nothing is copied into the browser.

      Bulk import from a spreadsheet (CSV)

      One card per row. Columns: name, type, grade, power, shield, critical, trigger, sentinel, persona, nation, race, image, text. Only name is required. A card with the same name is updated instead of duplicated. Images: put files in the images folder and write the file name (e.g. vyrgilla.png). Save from Excel/Google Sheets as "CSV UTF-8" so Thai and symbols stay correct.
